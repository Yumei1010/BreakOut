## 附：撰写原则

1. **每节独立**：改一节不动其他节——加玩法 = 加 4.x 节，改数值 = 改 4.x 表
2. **内容表优先**：能表格化的不写散文（字段即契约，对应代码注册表）
3. **先核心循环**：1-3 节定骨架，4 节以后是填充
4. **拓展钩子必写**：每系统标注"如何不加代码加内容"，防止未来推倒重来
5. **服务于代码**：字段名与代码注册表对应，策划→开发零翻译损耗
