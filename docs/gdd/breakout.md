## 一、游戏是什么

一款街机风格的打砖块游戏，用挡板反弹小球、撞碎砖块得分。

![游戏整体画面](images/Pasted%20image%2020260909135242.png)

## 二、玩家怎么玩

1. **发球**：按空格发射吸附在挡板上的球
![发球](images/Pasted%20image%2020260909135545.png)
2. **击球**：移动挡板反弹球，用球撞碎砖块
![击球](images/Pasted%20image%2020260909135615.png)
3. **得分**：撞砖得基础分，连续击球有连击加成
![得分](images/Pasted%20image%2020260909135801.png)
4. **过关**：清空本关全部普通砖 → 进入下一关
![过关](images/Pasted%20image%2020260909140128.png)
5. **失败**：球落底 3 次 → 游戏结束 → 查看结算统计 → 重新开始
![失败结算](images/Pasted%20image%2020260909135436.png)

## 三、流程是什么

开始 → 发球 → 打砖 →清空砖块过关 → 下一关 /球落底 3 次失败结算 → 重开

## 四、亮点有什么

多种多样的技能：
- 撞普通砖积累能量， 能量满后可使用激光，清空能量，射出一道贯穿光束，瞬间摧毁路径上的砖
- 冲刺可以短距离快速移动
- 磁力可以把球拉回挡板重新瞄准
快节奏的打击反馈：
- 挡板移动**平滑**，起步和停止都有惯性，不僵硬
- 挡板移动时会轻微摆动，手感更活
- 球撞挡板不同位置会不同角度弹出
- 球碰挡板/砖，会有轻微震屏 + 撞击声 + 小粒子迸溅
- 砖块被摧毁，会喷发出碎裂粒子 + 计分飘字
- 球落底，慢动作特写 + 画面变灰 + 岩浆溅射
- 完美击球，金色文字提示 + 更强反馈
- 球速极快时，球变红 + 拖尾线 + 加速粒子

砖有不同种类，每种有自己的血量、出现概率和特殊效果：

| 砖块  | 血量   | 出现概率 | 特殊效果         |
| --- | ---- | ---- | ------------ |
| 普通砖 | 1-3  | 较高   | 血量越高越硬       |
| 爆炸砖 | 1    | 低    | 摧毁时连锁引爆周围砖   |
| 能量砖 | 1    | 较低   | 摧毁时直接充满能量槽   |
| 金属砖 | 4    | 低    | 不吃连锁爆炸，要单独打  |
| 彩虹砖 | 1    | 低    | 每次受击变色，摧毁分数高 |
