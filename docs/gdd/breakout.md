# BreakOut GDD

> 面向开发/AI 的执行契约。加玩法 = 加表行/加系统节；字段名对应 `scripts/rules` 注册表。

## 1. 概念

街机打砖块 + 手感反馈（juice）+ 数据驱动拓展。单局 5-10 分钟。

**循环**：移动板 → 击球 → 撞砖计分 → 清砖过关 / 落底×3 结束 → 重开

## 2. 系统

### 2.1 球板运动（rules/ball, rules/bump）

| 规则 | 值 |
|---|---|
| 板加速/减速 | accel 20 / deccel 10 |
| 板振荡器 | spring 150 / damp 10 / vel×2 |
| 球速基准/上限 | 400 / 1200 |
| 反弹边缘倾斜 | ±15° |
| bump 判定 | PERFECT <5帧 / LATE 5-20 / EARLY 其余 |
| bump 增益 | 1.3 / 1.15 / 1.0 |

边界：吸附时锁定跟随；hitstop 帧冻结。
拓展：`BallMotion` 加反弹形态；`BumpJudge` 加等级。

### 2.2 砖墙（rules/brick）

| 规则 | 值 |
|---|---|
| 生成 | 锚点 × 填充率 0.9 × 权重表 |
| 爆炸连锁 | 半径 120，10 伤 |
| 能量砖 | 摧毁补满能量 |
| 清场条件 | 普通砖全毁 |

| 砖种 | 血量 | 权重 | 行为 |
|---|---|---|---|
| One/Two/Three | 1/2/3 | 35/30/20 | 普通 |
| Explosive | 1 | 5 | 连锁 |
| Energy | 1 | 10 | 补能量 |
| Metal | 4 | 6 | 免疫连锁 |
| Rainbow | 1 | 4 | 受击变色 |

拓展：**加砖 = `BrickCatalog` 加一行**。

### 2.3 能力（rules/ability）

| 能力 | 消耗 | 冷却 | 效果 |
|---|---|---|---|
| Dash | 0 | 1s | 冲刺+残影 |
| Laser | 满能量 | — | 清能量，范围 100 伤 0.4s |
| Magnet | 0 | 2s | 召回球 |

能量：撞普通砖 +10，能量砖 +100，上限 100，满触发提示。
拓展：`AbilityRule` 加枚举 + 规则。

### 2.4 计分（rules/scoring）

| 项 | 值 |
|---|---|
| 触碰/摧毁 | 50×combo / 200×combo |
| 连击超时 | 2s 清零 |
| 结算 | EARLY/LATE×500 + PERFECT×2000 + 反弹×10 + 对局分 |

### 2.5 特效（system/effect）

| 事件 | 反馈 |
|---|---|
| 碰板/砖 | 音效+震动+粒子+Pattern 脉冲（强度分级） |
| 砖毁 | 碎裂粒子+计分（CQRS 事件） |
| 球落底 | 慢动作+灰阶+岩浆溅射 |
| 过关 | 短促慢动作+结算弹层 |
| 高速球 | 变红+拖尾+速度粒子 |

纪律：每帧物理/juice 表现层直写；规则级变化（球死/砖毁/bump）走 CQRS 事件。

## 3. 状态

```
待发球 →(发球) 进行中 →(清砖) 过关结算 / (落底×3) 游戏结束 → 重开
```
