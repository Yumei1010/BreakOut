# BreakOut 游戏策划案

> 本文档给团队所有人看：策划、美术、程序、测试。用通俗语言描述"游戏是什么、怎么玩、能怎么扩展"，不涉及代码实现细节。

## 一、游戏是什么

一款街机风格的打砖块游戏：用挡板反弹小球、撞碎砖块得分。玩法上手简单，但击球时机、能量技能和砖块连锁爆炸带来了操作深度，快节奏的打击反馈（震屏、特效、音效）是游戏的核心爽点。

单局时长：5-10 分钟。

## 二、玩家怎么玩

1. **发球**：按空格发射吸附在挡板上的球
2. **击球**：移动挡板反弹球，用球撞碎砖块
3. **得分**：撞砖得基础分，连续击球有连击加成
4. **过关**：清空本关全部普通砖 → 进入下一关
5. **失败**：球落底 3 次 → 游戏结束 → 查看结算统计 → 重新开始

## 三、核心系统

### 3.1 挡板与球的操控

- 挡板移动**平滑**：起步和停止都有惯性，不僵硬
- 挡板移动时会**轻微摆动**，手感更活
- 球撞挡板不同位置会**不同角度弹出**（边缘偏折更明显）
- **击球时机**：球离板后，在合适的时机再按一次击球键可以"接住"反弹加成——时机越准奖励越高（分三档：完美 / 稍晚 / 稍早）

### 3.2 砖块

砖有不同种类，每种有自己的血量、出现概率和特殊效果：

| 砖块 | 血量 | 出现概率 | 特殊效果 |
|---|---|---|---|
| 普通砖 | 1-3 格 | 较高 | 血量越高越硬 |
| 爆炸砖 | 1 | 低 | 摧毁时连锁引爆周围砖 |
| 能量砖 | 1 | 较低 | 摧毁时直接充满能量槽 |
| 金属砖 | 4 | 低 | 不吃连锁爆炸，要单独打 |
| 彩虹砖 | 1 | 低 | 每次受击变色，摧毁分数高 |

### 3.3 能量与技能

- 撞普通砖积累能量，撞能量砖直接充满
- 能量满后可使用**激光**：清空能量，射出一道贯穿光束，瞬间摧毁路径上的砖
- **冲刺**：短距离快速移动（带残影效果），有冷却
- **磁力**：把球拉回挡板重新瞄准，有冷却

### 3.4 分数与结算

- 撞砖 +50、摧毁 +200（乘以连击数）
- 连续得分叠加连击，停顿 2 秒连击清零
- 每局结束结算页展示：击球时机统计、反弹次数、通关时间、总分

### 3.5 打击反馈（手感核心）

| 事件 | 玩家能感受到 |
|---|---|
| 球碰挡板/砖 | 轻微震屏 + 撞击声 + 小粒子迸溅 |
| 砖块摧毁 | 碎裂粒子 + 计分飘字 |
| 球落底 | 慢动作 + 画面变灰 + 岩浆溅射 |
| 完美击球 | 金色文字提示 + 更强反馈 |
| 球速极快 | 球变红 + 拖尾线 + 加速粒子 |

## 四、流程

开始 → 发球 → 打砖 →（清空）过关 → 下一关 /（球落底 3 次）结算 → 重开

## 五、怎么扩展（给策划/美术的内容清单）

**直接加内容（不改玩法规则）**：
- 新增砖块种类（定义血量/概率/效果即可）
- 新增技能（定义消耗/冷却/效果即可）
- 新关卡布局、新音效、新贴图

**需要先开会讨论的扩展**：
- 道具掉落、护盾等新系统
- 皮肤/主题系统

## 六、明确不做

- 不做联机对战
- 不做随机词条（保持玩家自主选择的难度叙事）
- 不做多球操控（会破坏单一焦点的手感）
